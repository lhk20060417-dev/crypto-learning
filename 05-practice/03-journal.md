# 第 3 节：交易日志

## 本节目标
- 理解交易日志为什么比预测更重要
- 掌握单笔日志和周期日志的记录方法
- 学会从日志中提炼改进点

## 核心概念

**交易日志是你的"交易黑匣子"。** 飞机失事后靠黑匣子找原因；交易亏损后靠日志找病根。没有日志，你的"经验"只是被记忆美化过的错觉。

**单笔日志模板（每笔必记）：**

| 项目 | 内容 |
|------|------|
| 日期 / 币种 | 何时、买什么 |
| 方向 / 仓位 | 多/空、占总资金比例 |
| 入场理由 | 为什么买（策略信号？规则第几条？） |
| 入场价 / 止损价 / 目标价 | 进场前先写下 |
| 出场价 / 出场理由 | 止损触发？目标到达？还是临时决定？ |
| 盈亏金额 / R 倍数 | 实际盈亏 ÷ 初始风险 |
| 截图 | 进场和出场时的 K 线图 |
| 情绪记录 | 当时的心情和冲动（关键！） |
| 复盘备注 | 事后补：做对了什么、违反了什么 |

**R 倍数**：把每笔交易换算成"初始风险的倍数"。止损离场 = -1R；止盈在 3 倍风险处 = +3R。这样不同仓位、不同币种的交易可以统一比较。

**周期日志（每周/每月统计）：**
- 交易次数、胜率、平均盈亏比、总 R 值
- 最大单笔亏损、最大回撤
- 按策略分类的表现（哪种信号赚钱最多？）
- 按情绪分类的表现（冲动交易 vs 计划交易的差异）

**日志的价值在三个"对比"：**
1. **计划 vs 执行**：止损被改过吗？加过计划外的仓吗？
2. **感觉 vs 数据**：你以为自己胜率高，统计出来可能只有 35%
3. **不同市场状态的表现**：牛市赚的钱是能力还是行情？日志能告诉你

## 举例说明

- 月度统计发现：按规则进场的交易平均 +1.8R；临时起意的交易平均 -1.2R → 结论：你的能力在规则内，所有亏损都来自手痒——以后只做计划内交易

## 常见误区

- ❌ "记在脑子里就行" → 记忆会被结果篡改：赚钱的交易越想越英明，亏钱的越想越"差点就对了"
- ❌ "只记亏损的" → 盈利交易里的坏习惯（比如靠运气扛过止损）不记录就永远不会被发现
- ❌ "记流水账没有意义" → 没有情绪字段和出场理由的日志只是对账单，不是训练工具

## 关键术语

| 中文 | 英文 |
|------|------|
| 交易日志 | Trading Journal |
| R 倍数 | R-Multiple |
| 最大回撤 | Max Drawdown |
| 交易统计 | Trading Statistics |

## 本节小结
1. 日志是黑匣子：没有它，复盘无从谈起
2. 单笔记九项：理由、价位、R 倍数、截图、情绪缺一不可
3. 周期看三对比：计划 vs 执行、感觉 vs 数据、行情归因

## 测验题

**1. 选择题：R 倍数的意义是？**
- A. 衡量杠杆大小
- B. 把每笔交易统一换算成初始风险的倍数，便于跨交易比较
- C. 计算手续费
- D. 排名用

<details>
<summary>点击查看答案</summary>
答案：B
解析：R 倍数标准化了不同仓位和币种的交易结果，是日志统计的核心指标。
</details>

**2. 判断题：交易日志只需记录亏损的交易，盈利的不用记。**
<details>
<summary>点击查看答案</summary>
答案：错误
解析：盈利交易中的坏习惯（违规扛单、运气止盈）同样需要暴露，只记亏损会得出一半的结论。
</details>

**3. 选择题：日志中"情绪记录"字段的主要作用是？**
- A. 抒发感情
- B. 发现情绪与违规操作的关联，针对性训练
- C. 给别人看
- D. 没有实际作用

<details>
<summary>点击查看答案</summary>
答案：B
解析：多数纪律违规发生在特定情绪状态下，找到规律才能针对性修正。
</details>
