# 布林带（Bollinger Bands）

## 本节目标
- 理解布林带的构造（中轨、上下轨）
- 掌握收口（Squeeze）与开口（Bulge）的用法
- 会用 %b 指标量化价格在通道中的位置

## 核心概念

**布林带由三条线构成：**
- **中轨**：20 日移动平均线
- **上轨** = 中轨 + 2 倍标准差
- **下轨** = 中轨 − 2 倍标准差

**核心逻辑：标准差衡量波动率。** 波动小的时候轨道自动收窄，波动大的时候自动张开——布林带是"自适应"的通道。

**两种关键状态：**

1. **收口（Squeeze，带宽收缩）**：波动率压缩到极致，往往是**大行情的前奏**。此时不要押注方向，等突破后顺势跟进。口诀：**收口必破，只等方向**。
2. **开口（Bulge，带宽张大）**：趋势正在展开。价格沿上轨运行 = 强势多头（别做空）；沿下轨运行 = 强势空头。开口极大时要注意——**波动率均值回归，极度扩张后趋势可能接近尾声**。

**%b 指标（量化价格在通道中的位置）：**
- %b =（最新价 − 下轨）÷（上轨 − 下轨）
- %b = 0.5：正好在中轨；%b = 1：顶到上轨；%b > 1：突破上轨；%b < 0：跌破下轨
- 好处：不同价格、不同波动率的市场可以用同一标尺比较

**常见用法：**
- 收口后向上突破上轨 + 放量 → 趋势启动信号
- 价格触及上轨但 %b 明显低于前高（价格新高、%b 未新高）→ 动能背离

## 举例说明

- BTC 日线布林带收窄到数月最窄 → 两周后放量突破上轨，一波 40% 的主升浪启动
- 价格贴着上轨连续上涨五周，布林带张口巨大 → 历史经验：张口极大时追高风险收益比很差

## 常见误区

- ❌ "碰到上轨就卖、碰到下轨就买" → 强趋势中价格会"沿着轨道走"，这样做会卖飞整段主升浪
- ❌ "收口后随便赌一个方向" → 收口只告诉你"要动了"，不告诉你往哪动；赌方向不如等突破
- ❌ "布林带参数必须用 20/2" → 20/2 是默认值不是圣旨；调整参数前先理解它衡量的是什么

## 关键术语

| 中文 | 英文 |
|------|------|
| 布林带 | Bollinger Bands |
| 收口 / 挤压 | Squeeze |
| 开口 / 膨胀 | Bulge |
| 标准差 | Standard Deviation |
| %b 指标 | %b（Percent Bandwidth）|

## 本节小结
1. 布林带 = 均线 ± 2 倍标准差，自动适应波动率
2. 收口是蓄势信号（等方向），开口是趋势展开（顺轨道方向）
3. %b 指标把价格位置标准化，便于跨市场比较

## 测验题

**1. 选择题：布林带持续收口通常意味着？**
- A. 行情结束了
- B. 波动率压缩到极致，大行情正在酝酿，应等待突破方向
- C. 价格要归零
- D. 指标失效

<details>
<summary>点击查看答案</summary>
答案：B
解析：收口代表波动率极低，是趋势启动前的蓄力状态；方向未知，不宜提前押注。
</details>

**2. 判断题：强势上涨趋势中，价格触及布林上轨就应该立即卖出。**
<details>
<summary>点击查看答案</summary>
答案：错误
解析：强趋势中价格会沿上轨持续运行，"碰轨就卖"会卖飞主升浪；开口状态下应顺势持有。
</details>

**3. 选择题：%b 指标等于 1 表示？**
- A. 价格在中轨
- B. 价格正好触及上轨
- C. 价格跌破下轨
- D. 指标出错

<details>
<summary>点击查看答案</summary>
答案：B
解析：%b =（价格 − 下轨）/（上轨 − 下轨），%b = 1 即价格位于上轨，> 1 为突破上轨。
</details>
