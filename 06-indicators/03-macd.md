# MACD（Moving Average Convergence Divergence）

## 本节目标
- 理解 MACD 的三个组成部分
- 掌握金叉死叉与零轴的用法
- 会用 MACD 背离判断趋势衰竭

## 核心概念

**MACD 由三条要素构成：**
1. **DIF（快线）**：EMA12 − EMA26，两条指数均线的差离值
2. **DEA（慢线）**：DIF 的 9 日EMA，即 DIF 的平滑版
3. **MACD 柱**：DIF − DEA 的差值，柱状图显示

**基本信号：**
- **金叉**：DIF 上穿 DEA → 买入信号
- **死叉**：DIF 下穿 DEA → 卖出信号
- 柱体由负转正、由正转负：动能转变的更早提示

**零轴的重要性（常被忽视）：**
- DIF 和 DEA 在**零轴上方**运行 = 多头市场，金叉的可信度高、死叉多是回调
- 在**零轴下方**运行 = 空头市场，死叉的可信度高、金叉多是反弹
- 一句话：**零轴定方向，金叉死叉找时机**。零轴下方的金叉，胜率远低于零轴上方的金叉

**背离用法：**
- **顶背离**：价格新高，但 DIF 未新高 → 上涨动力衰竭
- **底背离**：价格新低，但 DIF 未新低 → 下跌动力衰竭
- 结合 RSI 背离互相印证，可靠性更高

**滞后性：** MACD 基于均线，天然滞后——它告诉你"趋势已经转变"，而不是"趋势将要转变"。用它抓转折点会慢半拍，用它确认趋势更称职。

## 举例说明

- 零轴上方金叉 + 价格回踩 MA20 企稳 → 顺势加仓点
- 零轴下方金叉 → 只当作反弹信号，不重仓，等价格站上零轴再认真看多
- 价格第三波新高，DIF 一波比一波低 → 顶背离 + 跌破 MA50 → 清仓信号

## 常见误区

- ❌ "金叉就买、死叉就卖" → 不看零轴位置的金叉死叉在震荡市会被反复打脸
- ❌ "MACD 能预测顶底" → 它是滞后确认指标，背离也只是警示
- ❌ "柱体翻红就是底部" → 零轴下方的柱体翻红只是下跌动能减弱，不代表转势

## 关键术语

| 中文 | 英文 |
|------|------|
| 指数平滑移动平均线 | EMA |
| 差离值 | DIF |
| 信号线 | DEA / Signal Line |
| 金叉 / 死叉 | Golden Cross / Death Cross |
| 零轴 | Zero Line |

## 本节小结
1. MACD = DIF + DEA + 柱，均线差离体系
2. 零轴定方向，金叉死叉定时机；零轴下方金叉只当反弹
3. 背离是趋势衰竭警示；指标滞后，用于确认而非预测

## 测验题

**1. 选择题：DIF 的定义是？**
- A. MA5 − MA10
- B. EMA12 − EMA26
- C. 收盘价 − 开盘价
- D. 上轨 − 下轨

<details>
<summary>点击查看答案</summary>
答案：B
解析：DIF 是 12 日与 26 日指数均线的差离值，反映中短期趋势差。
</details>

**2. 判断题：零轴下方的金叉和零轴上方的金叉，可信度相同。**
<details>
<summary>点击查看答案</summary>
答案：错误
解析：零轴代表多空分界；下方金叉在空头环境中只是反弹信号，胜率明显低于上方金叉。
</details>

**3. 选择题：价格创新高但 DIF 未创新高，这种现象叫？**
- A. 金叉
- B. 顶背离，上涨动力衰竭的警示
- C. 死叉
- D. 钝化

<details>
<summary>点击查看答案</summary>
答案：B
解析：价格与动量指标走势不一致即为背离，顶背离提示趋势可能终结，需价格信号确认。
</details>
