# KD 随机指标与威廉指标（Williams %R）

## 本节目标
- 理解经典随机指标（Stochastic）的 %K / %D
- 掌握威廉指标 %R 的读法（注意它是"反向"的）
- 知道两者的同源关系与使用场景区别

## 核心概念

**KD 随机指标（Stochastic Oscillator，George Lane 创立）**：比较收盘价与最近 N 日价格区间的位置。
- **%K** =（收盘价 − N 日最低）÷（N 日最高 − N 日最低）× 100
- **%D** = %K 的 3 日平滑（信号线）
- **读法**：>80 超买、<20 超卖；%K 上穿 %D 金叉买，下穿死叉卖
- 与 KDJ 同源：KDJ 是在 KD 基础上加了一条更灵敏的 J 线

**威廉指标（Williams %R，Larry Williams 创立）**：公式几乎一样，但结果**上下颠倒**：
- %R =（N 日最高 − 收盘价）÷（N 日最高 − N 日最低）× **−100**
- 数值在 **0 到 −100** 之间：**高于 −20 超买，低于 −80 超卖**（注意方向与习惯相反！）
- 事实上：**%R ≈ %K − 100**，两者只差一个符号平移，信息完全相同

**使用要点：**
- 两者都极其敏感，**只适合短线**；中线以上周期假信号成灾
- 超买超卖区 + 背离是最可靠用法：价格新低但 %R 不新低 → 底背离
- 强趋势中同样钝化，"超买后更超买"

## 举例说明

- 价格跌破前低创出新低，威廉指标却只到 −70（没到 −80，比上次超卖浅）→ 底背离，短线反弹参考

## 常见误区

- ❌ "%R 高于 −20 是强势可以追" → 那是超买区，追高是给短线派派发筹码
- ❌ "威廉指标和 KDJ 完全不同" → 两者同源（只差符号与平滑），选一个用即可
- ❌ "敏感 = 好" → 敏感意味着信号多、噪音多；迟钝意味着稳、滞后。工具没有优劣只有匹配

## 关键术语

| 中文 | 英文 |
|------|------|
| 随机指标 | Stochastic Oscillator |
| 威廉指标 | Williams %R |
| 超买 / 超卖 | Overbought / Oversold |

## 本节小结
1. KD 与威廉指标同源：%R ≈ %K − 100，读法方向相反（−20 超买 / −80 超卖）
2. 均为短线敏感指标，背离和超买卖区信号最可靠
3. 强趋势中钝化，不可单独使用

## 测验题

**1. 选择题：威廉指标 %R 的超买区是？**
- A. 高于 80
- B. 高于 −20（即接近 0）
- C. 低于 −80
- D. 等于 50

<details>
<summary>点击查看答案</summary>
答案：B
解析：%R 区间为 0 至 −100，高于 −20 为超买，低于 −80 为超卖——与多数指标方向相反。
</details>

**2. 判断题：威廉指标和 KDJ 是完全不同的两套指标。**
<details>
<summary>点击查看答案</summary>
答案：错误
解析：两者同源，%R ≈ %K − 100；KDJ 只是 KD 的衍生加强版。
</details>

**3. 选择题：使用 %R 底背离的正确姿势是？**
- A. 背离出现立即满仓
- B. 价格新低但 %R 未新低，作为短线反弹参考，等价格企稳确认
- C. 背离无效
- D. 用于月线长线

<details>
<summary>点击查看答案</summary>
答案：B
解析：背离是警示不是指令，需价格自身的企稳信号确认。
</details>
