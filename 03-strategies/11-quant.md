# 第 11 节：量化入门

## 本节目标
- 理解量化交易的基本概念
- 知道一个量化策略从想法到运行的流程
- 认识量化的门槛和常见误区

## 核心概念

**量化交易：把交易规则写成代码，让程序自动执行。** 排除情绪、执行纪律、可同时监控上千个标的——这是它相对人工的优势。

**一个量化策略的生命周期：**

1. **提出假设**：如"突破 20 日高点后买入，持有到跌破 10 日低点"
2. **回测（Backtest）**：用历史数据验证策略表现（收益率、最大回撤、胜率、盈亏比）
3. **样本外验证**：用策略设计时没看过的数据段再测一次，防止"过拟合"（只适配历史数据的花架子）
4. **模拟盘（Paper Trading）**：真实行情、虚拟资金，跑 1–3 个月
5. **小资金实盘**：验证滑点、手续费后的真实表现
6. **逐步放大**：确认与回测一致后再增加资金

**量化必备的基础能力：**
- 一门编程语言（Python 是主流）
- 基础统计知识（期望值、方差、显著性）
- 数据源和 API（交易所 API、行情库）
- 对策略"为什么赚钱"的逻辑理解（没有逻辑支撑的统计规律是不可靠的）

**现实的门槛：**
- 散户量化要面对的是机构级别的竞争对手
- 回测好 ≠ 未来好（过拟合、市场环境变化、手续费滑点侵蚀）
- 量化解决的是"执行和纪律"，不解决"没有优势"——策略本身没有正期望，代码再漂亮也是更快的亏钱机器

## 举例说明

- 用 Python + ccxt 库拉取历史 K 线，写双均线策略回测 2020–2024 年 BTC：年化 40%、最大回撤 35% → 再用 2025 年数据样本外验证，若收益崩塌说明过拟合

## 常见误区

- ❌ "量化 = 稳赚/躺赚" → 量化只是自动化执行，策略无优势照样亏损
- ❌ "回测收益 1000% 的策略可以直接上实盘" → 大概率过拟合或未计手续费滑点
- ❌ "买个量化机器人就能赚钱" → 你买到的是别人用剩下的策略 + 你的手续费
- ❌ "AI 可以预测价格" → 短期价格接近随机游走，AI 能做辅助，不能算命

## 关键术语

| 中文 | 英文 |
|------|------|
| 量化交易 | Quantitative Trading |
| 回测 | Backtest |
| 过拟合 | Overfitting |
| 样本外测试 | Out-of-Sample Test |
| 滑点 | Slippage |
| API | 应用程序接口 |

## 本节小结
1. 量化 = 规则代码化 + 自动执行，核心依然是策略的正期望
2. 回测 → 样本外 → 模拟盘 → 小实盘，一步都不能省
3. 警惕过拟合和"回测幻象"，警惕售卖中的"稳赚量化机器人"

## 测验题

**1. 选择题："过拟合"指的是？**
- A. 资金仓位太满
- B. 策略参数过度贴合历史数据，对未来失效
- C. 服务器过载
- D. 下单次数太多

<details>
<summary>点击查看答案</summary>
答案：B
解析：参数越多、拟合历史越精细，越可能只是"背诵历史答案"，样本外表现通常崩塌。
</details>

**2. 判断题：回测表现优秀的策略可以跳过模拟盘直接大资金实盘。**
<details>
<summary>点击查看答案</summary>
答案：错误
解析：回测忽略滑点、延迟、心理等因素；模拟盘和小资金实盘是验证真实表现的必经步骤。
</details>

**3. 选择题：量化交易相对人工交易的核心优势是？**
- A. 预测更准
- B. 排除情绪、纪律化执行、可同时监控大量标的
- C. 不需要策略
- D. 手续费更贵

<details>
<summary>点击查看答案</summary>
答案：B
解析：量化不改变策略的期望值，只是把执行做到极致；预测能力上并没有魔法。
</details>
