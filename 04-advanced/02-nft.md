# 第 2 节：NFT

## 本节目标
- 理解 NFT 是什么、为什么有价值
- 了解 NFT 的主要类型和应用
- 认识 NFT 投机狂潮的教训

## 核心概念

**NFT（Non-Fungible Token，非同质化代币）**：每个都独一无二、不可互换的代币。1 个 BTC 和另 1 个 BTC 完全等价（同质化）；而每张 NFT 都有独立编号和元数据（非同质化）。

**简单理解**：给数字内容（图片、音乐、游戏道具、证书）发一张"链上产权证"。它证明"某个地址拥有某个数字资产"，且转移记录公开可查。

**主要类型：**
1. **数字艺术品/头像**：如 CryptoPunks、无聊猿（BAYC）——2021 年狂潮的主角
2. **游戏道具**：游戏内的装备、土地以 NFT 形式存在，玩家真正拥有、可自由交易
3. **会员凭证/门票**：持有某 NFT 才能进入的社群、活动（Token-gating）
4. **数字身份与凭证**：学历证书、域名（如 ENS 域名就是 NFT）

**为什么有人买：**
- 艺术收藏与社区身份（数字时代的"名画 + 俱乐部会员卡"）
- 创作者版税：原作者可从每次转售中抽成（链上自动执行）
- 投机：低买高卖（2021 年多数参与者的真实动机）

**狂潮的教训：** 2021 年 NFT 总市值一度数百亿美元，大量头像 NFT 从几百万美元跌到几千美元，跌幅 95%+ 的比比皆是。流动性极差——想买时抢不到，想卖时没人接盘。**NFT 是流动性最差的风险资产之一。**

## 举例说明

- 你花 0.08 ETH 铸造了一个新项目的 NFT，期望像无聊猿一样涨 1000 倍；三个月后项目方失联，地板价跌到你挂 0.005 ETH 都卖不掉——典型的流动性陷阱

## 常见误区

- ❌ "买了 NFT 就拥有了图片版权" → 你拥有的是链上凭证，不一定包含版权；多数项目只卖"展示权"
- ❌ "NFT 都是骗局" → 链上凭证、数字产权的底层价值真实存在，只是 2021 年的估值是泡沫
- ❌ "地板价低 = 便宜 = 会涨" → 没人接盘的东西，价格再低也没有意义

## 本节小结
1. NFT = 链上数字产权凭证，核心价值是确权与流通
2. 应用：艺术品、游戏、会员、身份；投机只是其中一种用途
3. 流动性极差，泡沫期估值虚高，普通人参与以小额、兴趣为目的

## 测验题

**1. 选择题：NFT 与 BTC 的核心区别在于？**
- A. NFT 不能交易
- B. 每个 NFT 独一无二，不可互换
- C. NFT 不需要区块链
- D. BTC 更安全

<details>
<summary>点击查看答案</summary>
答案：B
解析：同质化代币可互换（1 BTC = 1 BTC）；NFT 每个都有唯一标识。
</details>

**2. 判断题：购买 NFT 自动获得图片的全部版权。**
<details>
<summary>点击查看答案</summary>
答案：错误
解析：多数 NFT 只包含所有权凭证和有限展示权，版权仍归创作者，需看具体项目条款。
</details>

**3. 选择题：NFT 市场最大的风险之一是？**
- A. 价格波动太小
- B. 流动性极差，想卖时可能无人接盘
- C. 政府强制回购
- D. 只能白天交易

<details>
<summary>点击查看答案</summary>
答案：B
解析：NFT 无标准做市商，买盘稀薄，地板价不等于能成交的价格。
</details>
